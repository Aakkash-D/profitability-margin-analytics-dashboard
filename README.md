# 📊 Profitability & Margin Analytics Dashboard

A data analytics project built using **SQLite, SQL, Python, Pandas, and Streamlit** to analyze sales performance, customer profitability, and contribution margins through SQL analytics and an interactive dashboard.

---

## 🚀 Project Overview

This project analyzes transactional sales data to generate business insights such as:

- Customer-level revenue and profitability
- Top-performing customers by region
- Month-over-month revenue trends
- Low-margin customers and products driving losses

The results are visualized through an interactive Streamlit dashboard with filters and charts.

# 📈 Task 1 - SQL Analytics

## 1. Total Revenue, Cost & Contribution Margin per Customer

Calculates:

- Total Revenue
- Total Cost
- Contribution Margin

using SQL aggregation and `GROUP BY customer_id`.

### SQL Concepts Used

- SUM()
- GROUP BY
- ORDER BY

---

## 2. Top 3 Customers by Revenue Within Each Region

Ranks customers based on total revenue inside each region.

### SQL Concepts Used

- Common Table Expression (CTE)
- ROW_NUMBER() Window Function
- PARTITION BY
- ORDER BY

This ensures every region has its own ranking.

---

## 3. Month-over-Month Revenue Trend

Aggregates sales monthly and compares revenue with the previous month.

### SQL Concepts Used

- strftime()
- SUM()
- CTE
- LAG() Window Function

This helps identify growth or decline in business performance over time.

---

## 4. Lowest Margin Customers & Products Driving Loss

Identifies the bottom 10 customers by contribution margin and determines which products contribute most to poor profitability.

### SQL Concepts Used

- CTE
- JOIN
- GROUP BY
- Aggregation

The JOIN reconnects customer-level margin calculations with transaction-level product information.

---

## Revenue Reconciliation

A validation query confirms:

```
Sum of Customer Revenue
        =
Total Revenue in sales_orders
```

This ensures analytical correctness.

# ▶️ How to Run

## 1. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

## 2. Load Data into SQLite

```bash
python load_data.py
```

## 3. Run SQL Validation Scripts

```bash
python test_query1_customer_margin.py
python test_query2_top_customers.py
python test_query3_monthly_trend.py
python test_query4_margin_analysis.py
python test_reconciliation.py
```

## 4. Launch Dashboard

```bash
python -m streamlit run app.py
```
